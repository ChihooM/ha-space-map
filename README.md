# space-map

把 Home Assistant 的设备投影回家里的**真实平面**——第一眼是「家」，不是「列表」。

一个零构建、单文件的 Lovelace 卡片。无 npm、无打包、无依赖，浏览器直接加载。

## 为什么

所有智能家居 App（包括厂商自己的）都按「房间」分组，但房间内部仍是**卡片列表**。
用户找设备靠的是**标签记忆**（"卧室·墙面开关 Z1"），而人在真实空间里找设备靠的是**位置记忆**（"床头那个"）。

界面的表征方式（枚举）和用户的心智模型（空间）对不上。

## 现在能做到什么

- 8 个房间的多边形 + 20 段墙体，按毫米级坐标渲染成 SVG
- 32 个设备点位按真实坐标落在图上
- 灯/开关/窗帘点击即控；双键面板弹两行
- 亮/灭用饱和度区分，掉线单独一色

## 用法

```yaml
type: custom:space-map
```

## 状态

v0.1.0 —— 整屋视图可用，单房间放大视图开发中。

## 数据

房间与墙体来自自建户型模型；设备坐标为人工标定（cm 为单位，原点左上，X 向右、Y 向下）。
